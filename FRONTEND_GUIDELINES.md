# Frontend Guidelines

## Design direction

- Premium, quiet, print-first editorial layout.
- Use restrained color, fine rules, whitespace, and type hierarchy instead of ornamental graphics.
- Keep all five templates distinct but minimal.

## Color and type

- Base ink: `#18201d`; muted copy: `#69736f`; paper: white.
- Accent is user-selectable and applied as `--page-accent`.
- Geist is the primary font.
- Master font size scales all cover typography while preserving hierarchy.

## Layout

- A4 portrait, 210 × 297 mm.
- Default left binding margin: 25.4 mm / 1 inch, adjustable from 12–40 mm.
- Cover middle uses a three-part typographic information band: assignment number, academic context, paper code.

## Components and states

- Editor fields must have visible labels and concise helper text.
- Range inputs need accessible labels and clear value outputs.
- Use visible focus styles and semantic buttons.
- Missing values render as an em dash.
